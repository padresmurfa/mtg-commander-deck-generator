# Sprint 1.1 — Acquisition & oracle normalisation

**Epic:** E1 Card pipeline · **Gate:** none (G1 is 1.2) · **Status:** `done` — [retro](../retros/1.1-acquisition.md)

## Goal

Turn Scryfall's bulk data into a normalised, `oracle_id`-keyed card set with resolved legality,
colour identity and a minimum paper price — the input every later epic treats as given.

## Why this next

E0 is finished: the memory model, the process model and the determinism harness are all in place,
and the harness has nothing but a stand-in to measure. This is the first sprint that produces
something real, and it is the one every other epic depends on — a deck is a set of cards, and until
cards exist there is nothing to simulate, search over or price.

It also has the shortest path to the project's first gate. **G1 (opcode coverage, sprint 1.2)** asks
whether enough of a real commander's card pool can be modelled at all, and it cannot be asked until
there is a real card pool to ask it about.

## Input from the 0.3 retro

- **The determinism harness is calibrated but unproven.** The six-way matrix runs against
  `mf/trial`, which has no game semantics. The first *real* data through the digest layers is the
  card table — so `preprocess` should feed the `preprocess` layer for real, and the golden file
  gains its first meaningful row.
- **A covered branch is not a tested branch.** Parsing is where this bites hardest: a field reader
  that is exercised by every fixture and asserted by none looks fully covered.
- **Mutation testing found four tests that passed for the wrong reason.** Budget for it here; a
  parser is mostly branches, so the coverage number will look reassuring long before the tests are.
- **No CI.** `make check` before every push; `make hook` if you want it enforced.
- **The stand-in is deleted in E2, not here.** `mf/trial` and its golden rows stay until there is a
  real opening phase.

## Exit criteria

- [x] Scryfall bulk data ingested from a local file into the card set
- [x] Cards grouped by `oracle_id`; printings are never entities
- [x] Minimum price across paper-legal non-foil printings, per `oracle_id`
- [x] Commander legality and colour identity resolved per card
- [x] The set is emitted with a content hash and re-reads identically
- [x] `make check` green at ≥95% line and branch

## Tasks

- [x] **T0 — Apply the two decisions to the design of record.** §8 said "a Node stage" and said
      nothing about fetching. Both change, and the superseded paragraph is quoted rather than
      silently rewritten. **First, not last**: every task below contradicts §8 as it stood.
      *Done when:* design §8 and a new `preprocessing:` block in the spec agree with each other and
      with what is about to be built.
- [x] **T1 — `mf/jstream`: one value at a time out of a huge array.** A buffered, string-aware
      scanner that finds each top-level element's extent and hands *that* text to `mf_json_parse` in
      a caller-supplied frame. Peak memory is one element.
      *Done when:* a multi-element array streams with the arena's high-water mark bounded by the
      largest single element rather than by the file; strings containing braces, brackets and
      escaped quotes do not confuse the scanner; a truncated array is an `mf_err` and not a crash;
      and an element larger than the buffer still works.
- [x] **T2 — `mf/scryfall`: one bulk object → one printing.** Field extraction and nothing else:
      `oracle_id`, name, colour identity, `cmc`, `mana_cost`, `type_line`, `games`, `prices.usd`,
      `legalities.commander`.
      *Done when:* each field is read, a missing or wrongly-typed field is a rejected printing with
      a reason rather than a crash, and the module has no opinion about merging.
- [x] **T3 — `mf/cards`: the merge rules.** Group by `oracle_id`; **minimum price in integer cents**
      across paper non-foil printings; colour identity as the union; commander legality as *legal if
      any paper printing says so*, with disagreements counted rather than resolved in silence.
      *Done when:* every rule has a test that fails when the rule is inverted, an oracle with no
      priced printing is flagged rather than priced at zero, and the merge is testable without any
      JSON.
- [x] **T4 — Normalisation: mana pips, type bitmask, CMC.** `{2}{W}{U}` → pip counts; a type line →
      a type and supertype bitmask; `cmc` → a small integer. Pure functions, no I/O, no JSON.
      *Done when:* hybrid, Phyrexian, X and colourless pips are each a decided case with a test, and
      a type line with an em-dash subtype section parses the same as one without.
- [x] **T5 — Deterministic emission and content hash.** Sort by `oracle_id`, emit JSONL, and feed
      the set to the `preprocess` digest layer.
      *Done when:* shuffling the input order leaves the output and the digest byte-identical — which
      is the first time the harness measures something real — and the golden file gains a row.
- [x] **T6 — `mfsim preprocess --bulk`, end to end.** The subcommand, fixtures, smoke and golden.
      *Done when:* a fixture bulk file with the awkward cases in it (only-foil printings, no price

      real process, and a missing `--bulk` is a usage error rather than a crash.
- [x] **T7 — Retro and amendments.** Including whether `reference/legacy-ts/` can go — that decision

## Decisions

| Decision | Status |
| -------- | ------ |
| **Where preprocessing runs** | **Decided: C**, in the same binary. A second toolchain is a second thing to install, pin and keep deterministic, and the only argument for Node was that a Node app already existed. It does not. `reference/legacy-ts/services` stays read-only reference for field semantics |
| **Whether `preprocess` fetches** | **Decided: no, it consumes.** `mfsim preprocess --bulk <file>`. The card table is an input to a deterministic core, so a subcommand that downloaded would condition the determinism invariant on the network and on the day it ran. Fetching is one documented command, run deliberately |
| Streaming vs. document parsing | **Decided: streaming, element at a time.** ~110,000 printings and several hundred megabytes; a parsed document would cost gigabytes for a result read once and discarded. The scanner finds extents, the existing parser reads one element into a stack frame |
| Price representation | **Decided: integer cents.** Prices arrive as decimal strings. Cents are exact and order-independent to sum, which is what §17.1 asks for anyway |
| Legality when printings disagree | **Decided: legal if any paper printing says so, and count the disagreements.** Legality is a property of the oracle card, so a disagreement is a stale record rather than a real distinction. The count is in the run artifact, so if it is ever non-zero somebody finds out |
| Whether `reference/legacy-ts/` can be deleted | **Not yet.** `CLAUDE.md` §6 puts that in the **E1** retro, once acquisition is genuinely ported — EDHREC and Tagger are not |

## Not in this sprint

Opcodes and the card struct (1.2, and G1). Equivalence classes, dominance chaining, skill floors,
price imputation and the binary card table (1.3). EDHREC and Tagger — Scryfall alone is enough to
reach G1, and pulling in three sources at once makes it unclear which one a defect came from.

The **32-byte card struct** is 1.2's budget, not this sprint's. What is emitted here is a JSONL
intermediate with names and strings in it, deliberately: the binary layout is decided once the
opcode encoding is known, and guessing it now would mean packing bits twice.
