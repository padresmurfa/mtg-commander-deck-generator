# Sprint 2.3 — Policies and the policy gap

**Epic:** E2 Opening phase · **Gate:** **G3 — policy gap discriminates** · **Status:** `not_started`

## Goal

The policy ladder from §5, and the gate that asks whether it means anything: does naive-versus-careful
separate decks known to be forgiving from decks known to be demanding?

## Why this next

2.2 built one policy and **built it badly on purpose.** Greedy will not cast a ritual to enable a
bigger spell. It sequences taplands by a flag rather than by whether the mana would actually be used.
Both were recorded at the time as value deliberately left on the table.

That gap is not a defect to fix quietly — §5 says the gap **is** the skill requirement. Measure the
same deck under a deliberately naive policy and under the best available one, and the difference *is*
the number. So the weak baseline is the instrument, not a shortcoming of it.

G3 asks whether the instrument reads anything at all. If the gap is noise, §5 is unfounded and the
bracket system is built on a measurement that does not exist.

## Exit criteria

- [ ] A careful policy that sequences the tapland by whether the mana would be used this turn
- [ ] A naive policy, written down as deliberately bad rather than merely simple
- [ ] All five §5 rungs expressed as data in the shape 2.1 and 2.2 settled — parameters, no callbacks
- [ ] Paired measurement: same seeds, same decks, both policies
- [ ] **The noise floor measured before the separation threshold is chosen**
- [ ] Fixture decks known to be forgiving and known to be demanding, each with its reason recorded
- [ ] **G3 measured and recorded** — passed, failed, or deferred with a reason
- [ ] `make check` green at ≥95% line and branch

## Tasks

- [ ] **T1 — The careful policy.** Play the tapland only when the untapped land would go unused.
      *Done when:* on a hand where it matters the two policies play different lands, and the
      difference is visible in `mana_wasted` rather than only in the log.
- [ ] **T2 — The naive policy.** Deliberately bad, and documented as such so nobody improves it.
      *Done when:* its header says what it is for and why improving it would destroy the signal.
- [ ] **T3 — The ladder.** Five rungs (§5), as rows.
      *Done when:* adding a rung is adding a row, and the per-game path still has no indirect call.
- [ ] **T4 — Paired measurement.** Common random numbers across policies (§7.8).
      *Done when:* the same game index gives both policies the same shuffle, so the difference is
      the policy and nothing else.
- [ ] **T5 — The noise floor.** How far apart do two runs of the *same* policy land?
      *Done when:* measured and recorded **before** T7's threshold is chosen. This is the hard part
      of G3 — "separation exceeding measurement noise" is meaningless until the noise is a number.
- [ ] **T6 — Fixture decks.** Known-forgiving and known-demanding, with the reason for each.
      *Done when:* the classification is argued from deck contents, not from the result.
- [ ] **T7 — Gate G3.** Measured, recorded, called.
      *Done when:* the retro carries the measured gap, the noise floor, the threshold and the call.
- [ ] **T8 — Retro and amendments.**

## Decisions to make

| Decision | Status |
| -------- | ------ |
| What "performance" means for a gate-only phase | **Open.** §3 says the opening contributes pass/fail and nothing else to fitness, so a *gap* needs a scalar the gate does not have. Pass rate is the obvious candidate and it is coarse; `mana_wasted` and `spells` are finer and are not what §5 means by performance. Decide before measuring |
| G3's separation threshold | **Open, and it depends on T5.** The precedent from G2 and 2.2 is that the threshold is fixed before the number is seen — but here the threshold is *relative to* a measured noise floor, so the rule to fix in advance is the **multiple**, not the value |
| Whether the mulligan differs per rung | **Open.** §4 says keep/mull judgment is one of the largest skill differentiators and that factoring it out would erase the signal. 2.1 built it as policy parameters, so the machinery is there; the question is whether the rungs actually differ in it or only in play |

## Risks carried in

- **A gate must be unable to pass vacuously** (2.1). Ask it of G3: what measurement would make the
  gap look real without one existing? Two policies that differ in name only would report a gap of
  zero, which fails — but a policy pair that differs in something *irrelevant* would report noise and
  might not.
- **A defect can hide from the state vector** (2.2). It reports the pool after everything untaps, so
  within-turn timing is invisible through it. A careful policy is *entirely* about within-turn
  timing, so this is a sharper risk here than it was there.
- **The metacard carries no amounts** (2.2). Draw and cost reduction both assume one. A policy cannot
  sequence around a number the model does not carry, so this bounds how careful "careful" can be —
  and it qualifies G3 the way it qualifies G1.
- **The bottoming rule is a guess** (2.1), now affecting every game played. It is a policy decision
  and this is the policy sprint.
