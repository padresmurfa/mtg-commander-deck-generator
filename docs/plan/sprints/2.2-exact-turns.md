# Sprint 2.2 — Exact turns 1–4

**Epic:** E2 Opening phase · **Gate:** none · **Status:** `not_started`

## Goal

Turns 1–4, exactly: land drops, mana availability, castability and sequencing, ending in a state
vector §3 can score.

## Why this next

G2 says the hand is dealt honestly. It says nothing about what happens next — and the opening phase
is a **feasibility gate**: *can this deck cast its spells and reach turn 5 functional*. That is the
question the entire opcode model was built to answer, and nothing has asked it yet.

It is also where `mf/trial` finally goes. That stand-in has carried the determinism matrix since 0.3
and exists to be deleted the moment a real phase exists.

## Exit criteria

- [ ] A turn loop: untap, draw, land drop, main phase — for four turns
- [ ] Mana availability computed from the opcode set, **including whether a land entered tapped**
- [ ] Castability decided **pip by pip**, never by converted cost
- [ ] A greedy sequencing policy, and an end-of-phase state vector
- [ ] Land-drop probabilities checked against the closed form (§13.1) — a second analytic anchor
- [ ] `mf/trial` deleted and the determinism matrix running on the real opening phase
- [ ] `make check` green at ≥95% line and branch

## Tasks

- [ ] **T1 — The turn loop.** Untap, draw, land drop, main phase, four times.
      *Done when:* turn one draws nothing on the play, the land drop is once per turn, and the loop
      is a pure function of `(deck, seed, game)`.
- [ ] **T2 — Mana availability.** From `produces` and `produces_max`, and **enters-tapped costs a
      turn** — 1.2.1 made conditional tapped-ness unmatched precisely because this is where it bites.
      *Done when:* a Guildgate is worth nothing the turn it lands and one mana thereafter.
- [ ] **T3 — Castability.** Pips against available colours.
      *Done when:* `{W}{W}` is uncastable off one Plains and a Command Tower, and `{1}{W}` is not —
      the distinction dominance already refuses to collapse (1.3).
- [ ] **T4 — Sequencing and a greedy policy.** Which land, which spell, in which order.
      *Done when:* the policy is parameters in the shape 2.1 settled, and playing a tapped land
      early rather than late is visible in the result.
- [ ] **T5 — The end-of-phase state vector.** What §3 scores.
      *Done when:* it is integers, digested, and carries no float that a reduction could reorder.
- [ ] **T6 — Land drops against the closed form.** P(made every drop through turn T) is a
      hypergeometric (§13.1) and `mf/hypergeo` already has the pieces.
      *Done when:* measured with a tolerance **fixed before the number is seen**, as G2's was.
- [ ] **T7 — Retire `mf/trial`.** Move the 6-way determinism matrix onto the real phase.
      *Done when:* `mf/trial` is deleted, not merely unused, and the matrix still passes at 1/4/8
      partitions × fresh/resumed.
- [ ] **T8 — Retro and amendments.**

## Decisions to make

| Decision | Status |
| -------- | ------ |
| On the play or on the draw | **Open.** They differ by a card, which is a large effect at this scale. §3 does not say; pick one and record it, or measure both and say which the objective uses |
| What the state vector holds | **Open.** §3 wants "reached turn 5 functional" — decide what that is *before* building the vector, or it becomes whatever was convenient to collect |
| Tolerance for T6 | **Open, and fix it before measuring**, exactly as 2.1 did. The G2 experience is the precedent |

## Risks carried in

- **A gate must be unable to pass vacuously** (2.1). The zero-sample case reported agreement it had
  never observed. Ask it of T6.
- **The bottoming rule is a guess** (2.1) with no oracle. It affects every hand this sprint plays.
- **Do not treat a class as a card** (1.3). Nothing here expands, but sequencing is the first thing
  that reasons about specific cards rather than counts.
