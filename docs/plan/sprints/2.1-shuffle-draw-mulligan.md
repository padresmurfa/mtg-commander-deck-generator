# Sprint 2.1 — Shuffle, draw, mulligan

**Epic:** E2 Opening phase · **Gate:** **G2 — analytic agreement** · **Status:** `not_started`

## Goal

An unbiased shuffle, a draw step, the London mulligan with per-policy keep and bottom rules — and
**Monte Carlo agreement with the hypergeometric closed forms**, which is gate G2.

## Why this next

E1 is complete: there is a binary card table and nothing reads it. G2 is the earliest point at which
the simulation core can be shown *wrong*, and everything later inherits whatever the shuffler and the
draw step do. A biased shuffle does not fail loudly — it skews every result consistently, which is
exactly the failure that survives to the end of a project.

## The gate

**G2 — does the sampler converge to closed-form hypergeometric truth?** ([gates.md](../gates.md))
The shuffler, the draw step and the mulligan loop are the one part of this system with an *exact*
answer available: the probability of k lands in an opening seven from a 99-card deck is a
hypergeometric, not an estimate. *On failure:* the simulation core is wrong and must be fixed before
anything is built on it — every later result would inherit the defect.

The oracle is `reference/legacy-ts/.../deckAnalyzer.ts` (design §13.1), which is the one part of the
TypeScript tree that still has a job to do. Porting its closed forms is T5.

## Exit criteria

- [ ] A deck is 99 `uint8` indices into the card table (`l1_resident_hot_set`)
- [ ] Fisher-Yates over `mf/rng`, **bounded by rejection rather than modulo**, keyed by work item
- [ ] The London mulligan, with keep and bottom rules that a policy supplies rather than hard-codes
- [ ] Hypergeometric closed forms, ported and tested against hand-computed values
- [ ] **G2 measured and recorded in the retro**: the agreement, the sampling error, the pass/fail call
- [ ] `make check` green at ≥95% line and branch

## Tasks

- [ ] **T1 — `mf/deck`.** 99 `uint8` indices into the card table, plus the commander.
      *Done when:* a deck round-trips through the table's class ids, and the hot struct is measured
      against the L1 budget rather than assumed to fit.
- [ ] **T2 — Fisher-Yates.** Over `mf_rng_below`, which already rejects rather than folding.
      *Done when:* a chi-squared over permutation positions is within tolerance, **and** the same
      (seed, work item) shuffles identically however the work was partitioned — the property
      `determinism` exists for.
- [ ] **T3 — The draw step and an opening hand.**
      *Done when:* seven cards, no card drawn twice, and the library's remaining order is the
      shuffle's order minus what was drawn.
- [ ] **T4 — The London mulligan.** Draw seven, decide, bottom N.
      *Done when:* the keep rule and the bottom rule are supplied by the caller, so §5's policy ladder
      has somewhere to attach, and a mulligan to zero terminates.
- [ ] **T5 — The hypergeometric oracle.** Ported from `deckAnalyzer.ts` (§13.1).
      *Done when:* it agrees with values computed by hand for small cases, because an oracle nobody
      checked is not an oracle.
- [ ] **T6 — G2.** Monte Carlo against the closed form, over land counts and hand sizes.
      *Done when:* the measured agreement, the sampling error and the call are in the retro. A gate
      is passed, failed, or deferred with a reason — never "done".
- [ ] **T7 — Retro and amendments**, including what Tagger was for (see Decisions).

## Risks carried in

- **Mutation testing has found what advance tests did not, three sprints running.** A shuffler is
  exactly the kind of code that passes plausible tests while being subtly wrong, so budget for it.
- **Do not treat a class as a card** (1.3). 29,681 cards are 2,698 choices, and expansion has to
  re-validate. Nothing in this sprint expands, but T1 is where the class/card distinction first
  becomes something the simulation touches.
- **The determinism harness is still `mf/trial`**, a stand-in with no game semantics. It exists to be
  deleted once a real opening phase exists (spec `determinism_matrix.running_against`). That is this
  epic, and probably 2.2 rather than here.

## Not in this sprint

Turns 1–4 (2.2) and the policy ladder proper (2.3). This sprint ends with a hand, honestly dealt.
