# Sprint 0.1 — Greenfield skeleton

**Epic:** E0 Foundations · **Gate:** none · **Status:** `done`

## Goal

A C binary that builds, dispatches subcommands, loads config, writes a JSONL artifact, and is
covered by tests at ≥95% line and branch. No simulation, no card data.

## Why this first

Every later sprint needs somewhere to put code and something to run it with. Getting the
conventions wrong here is cheap now and expensive after twenty files exist. The coverage
harness in particular has to exist before there is code to leave uncovered.

## Exit criteria

- [x] Repo reset to greenfield; TS preserved as read-only reference
- [x] `make` builds a binary
- [x] Subcommand shell dispatches
- [x] Config loads
- [x] JSONL artifact writes
- [x] `make check` passes with ≥95% line and branch coverage

## Tasks

- [x] **T1 — Reset the repo to greenfield.** UI, pages, store, `infra/`, Docker and build config
      removed. Scryfall/EDHREC/Tagger clients, `deckAnalyzer.ts` and `types/index.ts` preserved
      under `reference/legacy-ts/`, excluded from build. `README.md` rewritten for the CLI project.
- [x] **T2 — Repo layout.** `src/ include/ tests/ tools/ docs/` created. `src/README.md` states
      what belongs where. `.gitignore` rewritten for a C project.
- [x] **T3 — Build system.** Plain `Makefile` (not CMake — one target, one machine). Targets
      `all debug test coverage check clean`. Release flags
      `-O3 -mcpu=apple-m1 -fno-fast-math -ffp-contract=off -std=c17 -Wall -Wextra -Werror`;
      debug adds `-g -O0 -fsanitize=address,undefined`. `make` produces a runnable binary.
- [x] **T4 — CLI shell.** `preprocess eval optimize validate` dispatch to stubs that report
      not-implemented and exit non-zero. `--help` and `--version` work. Unknown subcommand exits
      non-zero with usage. Global `--config` and `--out` parsed before dispatch.
- [x] **T5 — Config loading.** Minimal JSON reader written in-tree (see design amendment).
      Config file parses into a typed struct; defaults from `simulator-spec.yaml`; **unknown keys
      are an error, not ignored**; missing file falls back to defaults; type mismatches and
      out-of-range values rejected with a specific error.
- [x] **T6 — Resolved-config echo.** The fully resolved config (defaults + file + flags)
      serialises to JSON and is written as the first record of every run artifact.
- [x] **T7 — JSONL artifact writer.** Append-only, buffered, explicit flush points, no allocation
      per record, one writer per run, path from config.
- [x] **T8 — Test harness.** Minimal runner written in-tree (see design amendment). `make test`
      builds and runs; a failing assertion exits non-zero. Coverage measured by `llvm-cov` and
      enforced at 95% line and branch by `make coverage`.
- [x] **T9 — Error and logging conventions.** `src/README.md` records: no logging on per-game
      paths, log levels, `mf_err` propagation style, and what may allocate where.
