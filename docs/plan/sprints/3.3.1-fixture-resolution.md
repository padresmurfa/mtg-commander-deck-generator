# Sprint 3.3.1 — Fixture resolution

**Epic:** E3 Solo evaluation · **Gate:** **G4**, re-run · **Status:** `in_progress`

## Goal

Make G4 measurable. Not one of the 190 precons resolves completely against the card table, so the
corpus the gate needs is empty. This sprint decides — **in advance** — what a deck containing an
unrepresentable card *is*, and re-runs G4 with 3.3's thresholds unchanged.

## Why this next, and why not E4

**G4 did not fail. It could not be measured**, and a gate that has not answered is not one that has
been passed. E4 builds the search against the objective G4 exists to validate, and `gates.md` opens
by saying gates go as early as the dependency graph allows *because the point is to be wrong
cheaply*. Starting the search epic first spends exactly that saving.

Inserted on the 0.2.1 / 1.2.1 / 5.0 precedent — a numbered insertion with its reason recorded,
rather than a rewrite of a fixed epic.

## What was actually wrong, checked before designing round it

**Every precon card is in the paper card set.** 6,257 distinct ids, none absent. Exactly **two** are
not commander-legal — *Trade Secrets* and *Dockside Extortionist*, both banned in Commander, which is
the filter working. Everything else that is missing from the card table is missing for one reason:
`mf_opcode_representable` said no.

That matters, because it means **the facts a substitution needs are already on hand**. The card set
carries `cmc`, `pips`, `types` and colour identity for every one of them; only the *table* drops
them, and the table drops them because §7.9 prunes the search pool by representability. The blocker
was never data acquisition. (1.2.1's lesson, applied before assuming: a blocker recorded without
anyone going to look.)

**The table and the pool are the same set** — `mf_table_write` is called with `pool`, so widening the
table to carry these cards would widen what the GA may choose, which is precisely what §7.9 forbids.
So the substitutes have to come from somewhere that is *not* the pool.

## The rule, pre-registered

**Committed before anything is measured**, and before the code that would measure it exists. ρ =
−0.0137 has already been seen on patched decks, so choosing this in the light of it is the move
pre-registration forbids.

> **A card the opcode set cannot represent enters a *fixture* as the most neutral card of the same
> cost, type and colour identity that the model can express — and never enters the search pool.**
>
> - A **nonland** card keeps its mana value, its pips and its card types, and has **no modelled
>   effects**: no ramp, no draw, no cost reduction, no fetch.
> - A **land** keeps its types and additionally **taps for one mana of any colour in its identity**.
>   A land's whole modelled contribution is mana; a land that produced none would break the one
>   thing the substitution exists to preserve, and 563 of the 6,257 distinct precon cards are lands.

**Why this and not something cleverer.** It is not a new compromise — it is the compromise the model
*already* makes, applied one clause further. G1 measures 90.33% of clauses as **inert**: the card
table routinely carries cards whose text it almost entirely ignores. A card excluded outright for
having one unrepresentable clause is being treated *more harshly* than a card whose clauses are all
inert. The substitution makes the treatment uniform, and "cost, type, and whatever the model can
see" is the model's own standard already.

**What it distorts, written down now rather than discovered later.**

| Distortion | Direction | Reported as |
| ---------- | --------- | ----------- |
| Substituted nonlands contribute no ramp, draw or tutoring | **Understates** decks whose plan lives in unrepresentable cards | substituted count per deck, split land/nonland |
| A substituted land taps unconditionally for its identity | **Overstates** utility lands that really tap conditionally, or not at all | land substitutions counted separately |
| An unrepresentable **commander** becomes a vanilla of the same cost | **Understates** commander-centric decks badly, and it is 19% of precons | flagged per deck, and reported beside ρ |

The distortion is **deck-differential**, like 3.1's aggregation error, and it correlates with
commander complexity — so it is a bias G4 inherits and cannot correct, and the retro must say so
whichever way the number falls.

**The substitutes live outside the pool.** Preprocess writes them to a second table file, using the
existing writer with the oracle text stripped, so nothing about the format changes and nothing about
the pool does either. It is `mf/precon`'s own shape: a side table, joined at deck-scoring
granularity, which is where the question is asked.

## Tasks

- [x] **T1 — Diagnose, then pre-register.** *Done when:* the reason cards are missing is *measured*
      rather than assumed, and the substitution rule and its stated distortions are committed
      **before** the code that could measure their effect exists.
- [x] **T2 — The stand-in table.** `preprocess` writes it behind an optional `standin_table_path`,
      with the same writer and the same format. The stand-in is described **as oracle text and run
      through the same scanner** rather than built by a second path — a second path is a second
      place to disagree with the first.
      **The pool is untouched, and the test measures it**: the pool table's size with and without
      the stand-in path enabled, plus a disjointness check by oracle id. A stand-in reaching the
      search pool would silently undo §7.9.
      *A fixture gap the test found:* the bulk sample was **entirely representable**, so the
      stand-in table came out empty. It gains a recurring trigger — unwritable since 3.1, because
      `ops` has no repetition marker — and two pinned card counts moved with it.
- [x] **T3 — Resolution through the stand-in.** `mf_precon_deck` takes both tables and reports
      `substituted`, `substituted_lands` and `commander_substituted` separately. The deck is built
      field by field rather than through `mf_deck_build`, which indexes one table — and a
      substituted card carries **`MF_STANDIN_INDEX`**, not an index into anything, so nothing can
      expand one back into a card the optimiser may choose. `complete` keeps its 3.3 meaning:
      every card came from the *pool*.
- [x] **T4 — Per-deck completeness beside G1.** `preprocess` emits `coverage.per_deck` **inside the
      same object** as `legal_fraction` — `decks`, `complete`, `buildable`, `substituted`,
      `unresolved`, `commanders_substituted`, and the `min_gap`/`max_gap` spread, because "0 of 190"
      says nothing about whether the corpus was one card short or fifty.
      **Counts and not a fraction:** `complete` beside `decks` cannot be misread the way a lone
      `0.0` can, there is no division to guard, and the vacuous case is refused one step earlier —
      `mf_precons_load` rejects a file with no decks in it, so there is no untestable branch here.
      *A wrong label found on the way, and corrected in design, spec and `gates.md`:* the 3.3
      amendment called G1 "a fraction over clauses". It is a fraction over **cards** —
      `legal_representable / legal` — and it contradicted the per-card arithmetic in its own
      sentence. The conclusion is sharper stated correctly (0.9301<sup>100</sup> ≈ 0.0008), but a
      reader who took the label literally would have computed a much more forgiving implication for
      a deck. This is the second time G1 has been quoted as an answer to a question it was not
      measuring.
- [ ] **T5 — Re-run G4.** *Done when:* the verdict is recorded with **3.3's thresholds unchanged**,
      and the substitution counts are reported beside ρ rather than after it.
- [ ] **T6 — G4 in `mfsim validate`.** *Done when:* the number comes from the tool, as G1's and
      G2's do.
- [ ] **T7 — Retro and amendments.**

## Decisions to make

| Decision | Status |
| -------- | ------ |
| What a deck containing an unrepresentable card *is* | **Closed (T1), above, before the code.** Same cost, same type, same identity; no effects, except that a land taps for its identity |
| Whether a substituted deck is still a §13.2 fixture | **Open.** §13.2's first reason for using precons is that a precon is one exact published list. A substituted deck is not, and saying so honestly may mean G4 grades something weaker than it was written to grade — which is a real answer, not a failure to find one |
| Whether to grow the opcode set instead, or as well | **Deferred, not chosen.** It is the more expensive fix and the only one that makes the fixture genuinely the fixture. The substitution makes G4 *runnable*; it does not make the corpus *right*, and the retro must not let those be confused |

## Risks carried in

- **Thresholds must not move.** 3.3 fixed them before the data. Improving the instrument and
  loosening the bar at once makes the result unreadable — 3.1's rule, applied.
- **A fixture that patches itself hides the state of the world** (3.3). The hole-filling resolver
  was three lines, looked defensive, and turned an empty corpus into 35 plausible decks and a
  number. Whatever rule is chosen, the count of substituted cards is reported per deck.
- **Pre-registration protects the threshold and does not make you think of everything** (3.3). Three
  blind spots were named in advance and none of them is why G4 deferred.
- **G1's clause coverage does not bound per-deck completeness** (3.3), and the two were being read
  as though one implied the other.
- **The clock, three findings deep** (3.1, 3.2). G4 is still the first outside check on it, and it
  has not run.
