## The three decisions, and why they were made first

All three were open at planning and all three are written into the sprint
document **before any of the sprint was written**, because two of them changed
what got built.

**On the play or on the draw — both, alternating by game index.** The argument
that settled it is not about realism. A fixed choice biases the objective
*differentially*: the extra card is worth far more to a slow, expensive deck than
to a cheap one, so it moves the **ranking** and not merely the level — and the
ranking is exactly what G4 validates and could not see. Parity assignment is
exactly 50/50 over an even sample count, so it is proportional stratification
rather than randomisation, and it keeps §7.8's common random numbers intact.

**What the state vector holds — and what it deliberately does not.** §3 says the
gate's bar is *conditional on the strategy under test*, so the counts are in the
vector and the numbers are in a separate predicate. Keeping the threshold out is
what lets §5's five rungs disagree without replaying a game.

**T6's tolerance — 5σ, fixed in the sprint document.** Same rule and same
constant as G2. Re-deriving a threshold per measurement is how a threshold ends
up chosen to fit.

## The closed form the design named was right, and looked wrong

§13.1 lists "P(made all land drops through turn T)" as a closed form and cites
`computeLandDropProbabilities` in the legacy tree. That function's comment claims
the conjunction over turns and its body computes only the last term,
P(≥ T lands among the first T+6 cards). Those are different events and the
conjunction is a subset, so the comment could only be an overstatement.

**It is not. They are equal:**

> Exactly one card is seen per turn, so `L(t) − L(t−1) ∈ {0,1}`, and the
> requirement rises by exactly one per turn. So `L(t) ≥ t` implies
> `L(t−1) ≥ t−1`: the events are **nested**, and the conjunction collapses to its
> last term.

Checked with exact rational arithmetic against brute-force enumeration before
anything was built on it — which is the only reason a plausible accusation
against a piece of reference code did not become a wrong "fix" to the design.

Two things follow, and both are load-bearing:

- **The identity is the test's precondition, not a convenience.** Any extra card
  drawn, or any land put onto the battlefield by a spell, breaks the nesting at
  once. So T6 measures a deck that does neither — and a deck that *draws* is used
  as the negative case, failing the check, which is what says it has teeth.
- **It is not an independent oracle.** It is the same hypergeometric family G2
  used. What it adds is the code path: the turn loop's draw step and the
  land-drop rule, which G2 never touched. Worth saying, because "a second
  analytic anchor" reads stronger than it is.

## The defect mutation testing found, and how it hid

**A permanent entering the battlefield mid-turn contributed no mana that turn.**
The pool was collected once, before casting began, so a Sol Ring cast on turn one
paid for nothing behind it — the single most important accelerating line in the
format, silently absent.

How it stayed hidden is the useful part. The state vector reports mana
*entering the next turn*, when everything has untapped — so tapped-ness and
"arrived this turn" are invisible in it by construction. Every test that went
through a whole game agreed with the broken version.

It surfaced sideways. A mutation flipping the flag that says **a fetched land
arrives tapped** survived, and there is only one way that flag can have no
effect: if entering the battlefield changes no mana at all. The failing mutation
was two steps from the defect and pointed straight at it.

The test that now pins it runs a **one-turn** phase. Two turns would not separate
the implementations, because the second turn supplies the mana either way —
which is precisely how this survived being written.

## Mutation testing

Thirty-five mutations, all caught. Four tests were rewritten because a mutation
showed they pinned nothing, and two implementation defects came out of it.

| Mutation | First result | Then |

The three survivors that became design changes are the sprint's real output. A
mutation that survives because the code is right is information; one that
survives because *nothing can see the difference* is a design fault.

## What the coverage floor found

`run_turn_tests` was never registered in `tests/main.c`. The module ran green
under `make one` throughout and contributed **nothing** to the suite — 28
uncovered lines and 31 uncovered branches in a module whose own tests all passed.
Worth noting as a process defect rather than a code one: `make one` and `make
check` disagreed and only the floor noticed.

Once registered, the floor did its usual second job. It found:

- **One dead branch**, a guard for a fixed mana producer naming no colour — which
  every caller already excludes. Removed. This is the third sprint running where
  a refactor left an unreachable branch behind (0.2, 1.1, now here), and it is
  always the same shape: a guard that was live before the caller grew a check.
- **Seven guards nothing reached**, each now with a test that says what it is
  for: a source naming colours but no amount, a mask outside the six-bit colour
  space, a producer large enough to saturate the one-byte field, a ritual naming
  no mana, a fetch with no land left to find, a cost reducer, and a deck of
  free cantrips that empties its own library.

That last one is the guard's whole reason for existing: a zero-cost cantrip
chains until the library is gone, and the loop has to stop rather than draw from
nothing. Not a deck anybody can build — and termination is the assertion.

Two branches remain uncovered **deliberately**, both the same shape: at a
certainty (p = 0 or 1) a deviation is graded as infinite σ. Reaching them
requires a sampler that produces something arithmetic says is impossible. They
exist so that `0/0` becomes a failure rather than a NaN that compares false
against every threshold and passes silently. Recorded rather than removed.

## Design amendments

1. **§13.1 gains the nesting proof**, the precondition it implies, and the
   measured 1.74σ — with the note that this is the same oracle family as G2 and
   a different code path.
2. **§3 gains the state vector**: its fields, that it is thirteen bytes with no
   padding, why `mana_wasted` is in it, and that the threshold is *not*.
3. **§3 gains the play/draw rule** and the differential-bias argument for it.
4. **§17.1 gains what the matrix runs against** now that the stand-in is gone,
   including that the resume axis carries the kept hand — which is genuinely all
   a half-finished game has, where the stand-in's two integers were chosen to
   look plausible.
5. **Spec gains `land_drop_agreement`** beside `analytic_agreement`, and the
   `opening` phase entry gains the state vector, the gate defaults, the mana
   model and — importantly — its **known simplifications**.

## Revised risks

| Risk | Change |
| --- | --- |
| **The metacard cannot carry the amounts its opcodes need** | ⚠️ **New, and it qualifies G1.** `ops` records that a clause draws or discounts costs; nothing records *by how much*. Both assume one. Sprint 1.3 counted such a clause as **modelled** for G1, which is true of the opcode and false of the number. Fixing it means changing the class key, the table format and the content hash — a 1.3-scale change, so it is carried, not smuggled in |
| **A defect invisible to the state vector** | ⚠️ New. The vector reports the pool *after* everything untaps, so anything about timing within a turn is unobservable through it. One defect already hid there. Tests that need to see a turn go through the board API directly |
| **The bottoming rule is a guess** (2.1) | ↔ Unchanged, and now it affects every game played rather than only the hand |
| **`mf/trial` becomes permanent** | ✅ **Retired.** Carried since 0.3, deleted here. Three sprints of "it exists to be deleted" in three separate documents is what made it actually happen |
| **The greedy policy is not a good policy** | ⚠️ New, and deliberate. It will not cast a ritual to enable a bigger spell, and it plays taplands early or late by a flag rather than by whether the mana would be used. Both are exactly the value 2.3's careful policy has to find — G3 measures the gap, so a weak baseline is the point, not a defect |
| **Castability is exact but not fast** | ⚠️ New. Hall's condition is 64 masks per demanded subset, recomputed per spell. Correct first; §9's 1µs budget for the whole opening gate is unmeasured and 6.3 owns it |
