Threshold ≥0.60 sound, ≤0.30 compromised. **Call: PASS**, with the same condition as before and one

The 1.2 baseline was re-measured rather than quoted — the classifier from `6dc2ea3` was rebuilt and
run against the same export, and it reproduced 0.9357 / 29,783 / 89.4% exactly. Both numbers in the
table come from the same tool on the same file, and the artifact on disk from 1.2 turned out to be
the *pre-dual-land* run at 0.9249, which would have made a stale comparison very easy to publish.

## What was wrong

The prompt was an offhand observation: *those dual cards often enter tapped*. They do — 4,270 of
12,834 land printings say so — and following it found not one defect but the same defect five times.

**The classifier decided a clause from the first effect keyword it recognised, and asked whether the
model could express what it found in one branch out of five.** The mana branch checked, because the
dual-land bug in 1.2 had forced it to. `enters_tapped`, `cost_less` and `fetch_land` did not check
at all; `draw` checked partially. So:

| | Clauses | Was | Is |
| --- | ---: | --- | --- |
| Lands entering tapped **only under a condition** | 167 | `enters_tapped`, flat | `unmatched` |
| Cost reduction that **varies with the board** | 257 | `cost_less`, as if fixed | `unmatched` |
| Draw whose **quantity varies** | 124 | `draw`, as if fixed | `unmatched` |
| Effects on a **trigger these phases never run** | 662 | `unmatched` or a concrete opcode | `inert` |
| Land fetch **without the word "land"** | 49 | `inert` — "tutoring a spell, not ramp" | `fetch_land` |

Two carry the argument on their own:

- **`Clifftop Retreat enters tapped unless you control a Mountain or a Plains`** was recorded as
  entering tapped, full stop. The rule that would have caught it already existed six lines below,
  in a branch that never ran because this one returned first.
- **`Search your library for a Plains or Island card`** was recognised as ramp **only because
  "Island" contains the letters l-a-n-d**. The same effect written `Mountain or Forest` — Nature's
  Lore, Three Visits — was classified as a spell tutor and thrown away. An accident of English
  spelling was deciding 64 cards.

## The rule now

Three steps, and the first and third are what 1.2 had only in places.

1. **Reachability** — does the trigger fire inside the simulated phases? A clause gated on
   attacking, blocking, combat damage, dying or an opponent's action is **inert**, whatever it goes
   on to do.
2. **Shape** — what it does, in the observable currency.
3. **Expressibility** — a concrete opcode whose amount or condition depends on state the model does
   not carry is **unmatched**.

Step 3 leans on Magic's own templating, which turns out to draw exactly the line the model needs:
***when* fires once at a moment the model knows** — the card is cast, it enters — **whereas
*whenever* fires a count set by the rest of the deck.** A fixed opcode can stand for the first and
not the second. Missing that distinction was worth 392 clauses on its own, all of them repeating
triggers being recorded as one-shot effects.

## The finding that outlasts the sprint

**G1 goes up when less is simulated.** Reclassifying combat triggers as inert raised coverage while
modelling nothing new, and in the limit a model that simulates nothing scores 1.0. The headline only
fell because corrections in the other direction happened to be slightly larger.

That is a defect in the metric, not in this sprint's use of it, and it was invisible while the
number only ever moved for one reason. **The inert share is now quoted beside the fraction
everywhere the fraction appears**, and a rise in G1 accompanied by a rise in the inert share is
explicitly not an improvement. Recorded in spec `validation.opcode_coverage.metric_hazard` and
design §13.5.

Related and worth keeping in view: **1,454 clauses (2.0%) changed classification for a headline move
of 0.0032.** A near-cancellation of two large opposite corrections is not evidence that the first
answer was nearly right, and if the aggregate had been the only thing checked, none of this would
have surfaced.

## Assertions from 1.2 that were changed

Changing a passing test is how a suite gets talked into agreeing with the code, so each one is here
with its argument.

| Assertion | 1.2 | 1.2.1 | Why |
| --- | --- | --- | --- |
| `Whenever this creature attacks, draw a card` | `unmatched` | `inert` | Combat is not simulated, so the trigger never fires. Calling it unmatched charges the opcode set for the narrowness of the *phases*, and the gate then counts that narrowness twice |
| `You may draw a card` | `unmatched` | `draw` | §5's ladder contains no policy that declines a free card. Treating optionality as inexpressible would have made most enters-the-battlefield ramp unrepresentable — the opposite of true |
| `Each opponent may draw a card` | `unmatched` | `inert` | An opponent's draw does not change what this deck can cast, and the solo gate does not observe it |
| `Whenever a creature you control dies, draw a card` | `unmatched` | *(removed)* | Superseded by the reachability test, which covers the case with a stated reason |

## Mutation testing

15 mutations, 14 caught, and the one survivor was the most useful result of the exercise.

**Deleting the `"island"` land-type alternative changed nothing**, because `has("land")` matches
"Island" first — the very accident the sprint set out to remove had quietly reappeared as an
unreachable `||` alternative. Deleted, with the reason in a comment. Per the standing rule, an
alternative no test can distinguish is dead weight, not caution.

The three that survived the first pass and drove new tests:

- **`instead`** — 89 clauses turn on it alone, including
  `{1}: The next time you would draw a card this turn, you gain 5 life instead`, which contains
  "draw a card" and is precisely the *absence* of drawing one.
- **`swamp`** — hidden behind `Mountain` and `Forest` in the only test that exercised the branch.
  Now one row per basic type.
- **Letting the expressibility gate touch inert clauses** — no test pinned that an inert clause is
  allowed to say "unless". Without it, `Counter target spell unless its controller pays {3}` would
  join the unmatched column and the gate would collapse for a reason unrelated to modelling.

## Revised risks

| Risk | Change |
| --- | --- |
| **A classifier agrees with itself** | ⚠️ **Confirmed twice more, and no longer a risk so much as a property of this work.** The dual-land bug in 1.2, and five instances here. Every one was found by asking the real data what the classifier accepted; none was found by reading the classifier or by a failing test |
| **The gate answers a narrower question than it appears to** | ⚠️ **Worse than recorded.** Not only is the answer narrow, the metric *rewards* narrowing it. Mitigated by publishing the inert share alongside, never the fraction alone |
| **A stale artifact becomes the baseline** | ⚠️ New. `data/g1-run.jsonl` was the 0.9249 run, not the 0.9357 one, and using it would have produced a confident, wrong comparison. Baselines get regenerated from the commit that produced them |
| **Conditional lands are unmodelled** | ⚠️ New, and the largest actionable lever. `unless you control a Mountain` is a predicate the simulator *could* evaluate — it knows the battlefield — but the opcode payload has no room for one. This is now a direct input to the payload design carried into 1.3 |

## Carry-over

None of this sprint's own. The 1.2 carry-over (32-byte card struct, `--report-unmatched`) is
untouched and still bound for 1.3.
