### Not delivered

Nothing from the sprint scope. Four things a reader should know:

- **The card table is JSONL, not the binary table of §8.** Deliberate: the
  32-byte layout cannot be decided before the opcode encoding exists, and
  guessing it now would mean packing the bits twice. Sprint 1.3 owns it, and the
  config key is already `card_table_path`.
- **Prices that are absent stay absent.** Imputation needs the dominance
  relation, which is 1.3. A zero here would make a card look free, and the
  optimiser would take every one of them.
- **EDHREC and Tagger are untouched**, so `reference/legacy-ts/` cannot go yet.
  That decision belongs to the **E1** retro, as `CLAUDE.md` §6 says.
- **Nothing has run against the real 500 MB export.** Every test is a fixture.
  The streaming design is measured — a test asserts the arena's high-water mark
  stays under 128 KiB while streaming 2 MB — but "it handles a hundred thousand
  cards" is an argument, not an observation, until somebody downloads the file.

## The two decisions this sprint was blocked on

**Preprocessing runs in C**, in the same binary. Design §8 said "a Node stage,
run weekly" and `CLAUDE.md` §6 said the acquisition logic is *ported* in E1;
both could not be true. The Node argument was that a Node app already existed
around the project, and sprint 0.1 removed it. A second toolchain is a second
thing to install, pin and keep deterministic.

**`preprocess` consumes a bulk file; it does not fetch one.** The card table is
an input to a deterministic core — `same seed + config + card table ⇒
bit-identical output` — so a subcommand that downloaded would condition that
invariant on the network and on the day it ran. Fetching is one documented
command, run deliberately.

Both applied to design §8 in the same change, with the superseded paragraph
**quoted rather than silently rewritten**. A design of record that reads as
though it always said this is worse than one that says what changed.

## Design amendments

Three, all applied in the same change as this retro.

| Document | Change | Why |
| -------- | ------ | --- |
| `simulator-design.md` §8 | Rewritten: C rather than Node, *Acquisition is not preprocessing*, *The bulk file does not fit in an arena* | The section described a project that no longer exists, and said nothing about how a several-hundred-megabyte input is read |
| `simulator-spec.yaml` → `preprocessing` | New block | The merge rules cross a module boundary and are the part most likely to be argued about later. They needed a normative home |
| `config` | `bulk_path` added; `card_table_path` default `data/cards.bin` → `data/cards.jsonl` | The format is text until 1.3 decides the binary layout, and the default should not claim otherwise |

## What the tests bought this time

**The coverage floor found two dead branches**, both the "a refactor just made
this unreachable" pattern the 0.2 retro warned about: an end-of-input check in
the scanner that its only caller had already made, and a type check in
`array_contains` that its only caller had already made. Both deleted. It also
found a closing brace in the scalar delimiter set that cannot follow a top-level
array element — a branch that was never wrong, just never reachable.

**Mutation testing found a rule with no test.** `mf_types_parse` stops at the
subtype dash, and removing that stop changed nothing, because **no printed
subtype is currently spelled like a type**. The rule is still right — it is what
keeps a future subtype from silently becoming a type — so the test that pins it
is deliberately synthetic (`"Creature — Land"`), and says so. A rule worth having
is worth a test even when today's data cannot distinguish it.

**The most useful failure was in a test, not in the code.** The large-element
test hand-counted a string literal one byte short, which dropped a quote and
turned valid input into malformed input. The scanner was suspected for a long
time before the fixture was. Literal lengths now go through `strlen`, and the
lesson is in the file where the mistake was made.

**A truncated file must not read as a shorter one.** Three different cuts —
inside a string, between a key and its value, and between elements — reach three
different places in the scanner and all return `MF_ERR_PARSE`, so a test that
checks only the code cannot tell them apart. Pinning the *messages* forced two
improvements: the scanner now distinguishes a string left open from a value left
unclosed, and a file that stops after a complete element says "the array was
never closed" instead of blaming a missing comma.

## Revised risks

| Risk | Change |
| ---- | ------ |
| **Nothing has seen the real export** | ⚠️ New, and the biggest one here. 110,000 printings at several hundred megabytes will find things ten fixtures cannot: fields this code rejects that it should accept, a card whose name breaks an assumption, an arena size that converges somewhere inconvenient. The mitigation is that the arena *does* converge and the rejection counts are in the artifact, so the first real run reports its own surprises rather than hiding them |
| **The merge rules are decisions, not facts** | ⚠️ New. Hybrid counting toward both colours, `{2/W}` as its colour, permissive legality — each is defensible and each is a judgement that a later sprint may overturn. All are written down in `mf/card.h` next to the code, with the reasoning, so overturning one is an argument rather than an archaeology |
| **`mf/trial` becomes permanent** | ↔ Unchanged, but the pressure is off: the `preprocess` digest layer now carries real data, so the stand-in is no longer the only thing the harness measures |
| **No CI** | ↔ Unchanged. `make check` before every push |
| **`_FORTIFY_SOURCE` folded branches cap coverage** | ↔ 28 folded. Real uncovered branches are up from 1 to 10 — nine of them loop and delimiter conditions in two new parsers, and the tenth is still the `_exit`. Worth watching rather than chasing: the floor has headroom, but this is the first sprint where the number moved in the wrong direction |
| **Coverage floor unreachable in C** | ↓ Line 100%, function 100% for the fifth sprint running |
