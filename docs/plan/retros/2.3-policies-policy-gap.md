### Why defer rather than pass or fail

The three-way branch was written into the sprint document **before any of it was
built**, precisely so this case could not be forced into the wrong one:

| Primary | Secondary | Call |
| --- | --- | --- |
| separates | — | pass |
| flat | separates | **defer — the signal exists; the instrument cannot see it** |
| flat | flat | fail — §5 is unfounded |

The primary metric is the gate pass rate, because §3 sanctions exactly one output
from the opening phase and that is it. But §3 also insists the bar be **low**, so
that weighting opening strength does not breed out every control deck — and a
rate near 1.0 has almost no room to move. That hazard was named in advance, and
it is what happened: 0.86 → 0.94 under careful play on both decks.

A two-way gate would have forced "the skill signal does not exist" onto evidence
that only says "a binary pass/fail at a deliberately low bar cannot see one".
Those are different findings with different consequences, and the second does not
threaten §5.

## The finding the gate produced, which is bigger than the verdict

The gap was **decomposed** — total, play-only, mulligan-only — because §4 asserts
that keep/mulligan judgment is *"a large part of the measured skill gap"* and
nothing had ever tested that assertion.

| Component | Forgiving deck | Demanding deck |
| --- | ---: | ---: |
| Mulligan only | **+0.0761** | **+0.0745** |
| Land rule only | **+0.0000** | **+0.0123** |
| Both (the gate) | +0.0761 | +0.0868 |

**§4 is right, and that turns out to be a problem for §5.**

- The mulligan is roughly **88% of the total gap** — a large part indeed.
- It is **the same size on both decks**, so it discriminates *nothing*. In the
  difference of differences it very nearly cancels.
- The land rule is **exactly zero** on the deck with nothing to sequence and
  positive on the deck built to punish it. That is a perfect qualitative
  separation — and it is small.

So §5's gap is a sum of one large component that measures nothing about the deck
and one small component that measures exactly the right thing. **Averaging them
dilutes a clean signal with a large constant**, which is why the gate defers.

Measured on the land rule alone, the same comparison passes: forgiving gap
0.0000, demanding gap +0.0123, and 6.59σ at 2,000 games a block. That is
recorded as a **diagnostic beside the verdict, never in place of it** — the gate
compares the two ends of the ladder, and changing the comparison after seeing the
result is the thing the whole pre-registration discipline exists to prevent.

## The correction to my own threshold rule

**The rule as written in the sprint document was wrong, and it is disclosed
rather than quietly patched.**

"Separation greater than 5× a measured noise floor" is a **significance test**,
and a noise floor shrinks as 1/√N. So significance is free at scale: any non-zero
separation clears any multiple given enough games. The sprint fixed the
*multiple* in advance and never fixed the *sample size*, which left a free
parameter sitting directly on the verdict.

Measured, on the same comparison:

| Games per block | σ | verdict under the original rule |
| ---: | ---: | --- |
| 500 | 1.26 | defer |
| 1,000 | 2.26 | defer |
| 2,000 | 3.43 | defer |
| 4,000 | 3.52 | defer |
| 8,000 | **5.32** | **pass** |

Same effect, same decks, different answer. Picking the row is not a measurement.

The fix is an **effect size** alongside the significance test — the demanding
deck's gap must be at least 2× the forgiving deck's — because no sample size can
inflate a ratio. Under both criteria the verdict is **defer at every sample size
and all eight seeds tried** (ratio 1.10–1.17 throughout), which is why adding it
is a correction to the rule rather than a search for an answer: it makes the gate
strictly harder and changes nothing about the result.

**This applies to G4 and G5 and should be read as a general rule:** a gate
threshold expressed in standard errors is a threshold with the sample size left
blank. §5's brackets need decks *ranked*, and ranking needs an effect, not a
detection.

## What the opening phase cannot express

Recorded before measuring, because it bounds what this sprint can claim. Of §5's
six policies:

| Policy | Status |
| --- | --- |
| `greedy` | ✅ 2.2 built it, deliberately badly |
| `curve-out` | ✅ cheapest-first casting |
| `role-aware` | ~ partial — ramp is observable, removal and interaction are not |
| `sequencing-aware` | ✅ this sprint |
| `hold-interaction` | ❌ **meaningless with no opponent to hold mana up for** |
| `combo-assemble` | ❌ needs combo detection nothing builds yet |

So the experienced bracket's admissible set — `{role-aware, sequencing-aware,
hold-interaction}` — has one inert member and one partial one. That is a fact
about the phase rather than about the design, and it resolves when E5 gives the
model an opponent.

## Mutation testing

Twenty-three mutations against the new code, all caught after four tests were
rewritten. The instructive ones:

| Mutation | Result |
| --- | --- |
| The lookahead asks "is anything castable" instead of "anything *newly* castable" | **survived** → the two differ constantly, but only on a deck whose spells are cheap enough to be castable already. Now pinned by a deck where every spell costs one |
| Ramp-first breaks ties by cost descending | **survived** → and the reason is worth keeping: it is *not* an equivalent mutant, it is a **better policy** on that deck. A mana creature is summoning sick and a fetched land is not, so taking the expensive ramp first genuinely wins. The outcome assertion could not pin the rule; asserting the specification could |
| The lookahead ignores the cost discount | **survived** → no fixture had a cost reducer |
| A land in hand treated as castable by the lookahead | **survived, correctly** — a land costs zero, so it is payable from an empty pool and can never be *newly* payable. An equivalent mutant; the guard is kept because it states the rule where a reader looks for it |
| Careful collapsing to either of the two weak rules | caught |
| `is_ramp` missing land fetches | caught |
| The sequencing rung not being careful; the greedy rung not being naive | caught |

The ramp tie-break is the one to remember. **A mutation that survives because the
mutant is better is not a weak test — it is a lead**, and it is now recorded as
one: a rung that prefers ramp which is usable *this* turn over ramp that is
summoning sick would beat the one this sprint shipped.

## Design amendments

1. **§5 gains the decomposition** and the consequence: the gap is a sum of a
   large non-discriminating mulligan component and a small discriminating
   sequencing one, so a scalar gap is the wrong summary and the components
   belong reported separately.
2. **§4's claim is confirmed and qualified** — the mulligan *is* a large part of
   the gap, and that is exactly why the gap alone does not rank decks.
3. **§13/gates gain the threshold rule**: a gate threshold in standard errors has
   the sample size left blank. Effect size beside significance, for G4 and G5 too.
4. **§5 gains what the opening phase cannot express**, so the bracket tables are
   not read as though all six policies were live.
5. **Spec gains `policy_gap`** beside the other validation entries, with the
   three-way verdict rule, both thresholds, and the measured decomposition.
